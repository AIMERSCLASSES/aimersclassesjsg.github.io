SSC MTS Test 5 — Instructions

Session I: Numerical Ability (20 questions) and Reasoning Ability (20 questions). Duration: 45 minutes. Each correct answer carries 3 marks. No negative marking.

Session II: General Awareness (25 questions) and English Language (25 questions). Duration: 45 minutes. Each correct answer carries 3 marks; each wrong answer carries −1 mark.

Both sessions are mandatory in this practice test. Once Session I is submitted, you cannot return to it. The practice timer includes a pause option, which is not available in the actual SSC exam.

Choose the best answer for each question. Your score and explanations will be shown after you finish Session II.
