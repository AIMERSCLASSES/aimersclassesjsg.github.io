# AIMERS CLASSES Website

A free, GitHub Pages-ready coaching website.

## Included
- Responsive homepage
- Courses: Class 1–12, ICSE/CBSE/CHSE, Science/Commerce/Arts
- Competitive Exams: SSC, Railway, Banking
- Odisha Govt Exams: ASO, OSSC, OSSSC, RI, AMIN
- School Entrance: Jawahar Navodaya, Adarsha, Sainik School
- Study Material page for PDFs, videos and current affairs
- Demo online mock test with timer and automatic score
- Call and WhatsApp buttons
- Google Maps link
- Mobile-friendly design

## Important
This version is a free static website, so there is no database/admin login. You can add PDFs and links by editing `materials.html`, or later connect a free backend/CMS if you want upload-from-phone functionality.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this package.
3. In GitHub: Settings → Pages → Deploy from branch → main → /(root).
4. Save. Your site will receive a GitHub Pages address.

All main website text and contact details are already filled in.
